# Inbox

Unsorted capture and generated **drift reports**. Two jobs:

1. **Capture:** if something is worth keeping but has no obvious home yet, drop
   it here with a date, then file it into Projects / Areas / Knowledge later.
2. **Drift reports:** `drift-scan.ps1` and the `pai-drift-check` skill write
   dated reports here, named `drift-report-YYYY-MM-DD.md`. The newest one is the
   current accuracy state of the vault.

Keep this folder near empty. A full inbox means filing is overdue.
